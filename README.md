# Wallpaper Studio
Open index.html in a browser, or host the folder (GitHub Pages / Cloudflare Pages). No build step. Keep the src folder next to index.html.
Add shapes/text/images, drag to move, drag the white corner square to resize. Rounded rects have a Radius slider.
Glass Rect / Glass Circle (or the Liquid Glass toggle on any rect/circle) refract everything beneath them.
Keys: arrows nudge (shift = 10), [ ] rotate, Ctrl/Cmd+D duplicate, Ctrl/Cmd+Z undo (+Shift redo), Delete, Esc.
