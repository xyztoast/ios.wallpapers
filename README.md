# Wallpaper Studio
Open index.html in a browser (or host the folder on GitHub Pages / Cloudflare Pages). No build step.
Add shapes/text/images, drag to move, drag the white corner square to resize, edit in the right panel.
Keys: arrows nudge (shift = 10), [ ] rotate, Ctrl/Cmd+D duplicate, Ctrl/Cmd+Z undo (+Shift redo), Delete, Esc.
Autosaves to IndexedDB. Open/Save use portable .wallpaper.json. Export gives PNG/JPEG/WebP at full size.
